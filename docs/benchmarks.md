# Benchmark Scores

A comparison of models available through **GitHub Copilot** (native or extension), custom endpoints, and comparison-only API rows. Rows are ordered by the **current OpenRouter AA Intelligence Index** score (highest first); models without a current composite are listed after scored rows. Cells with `—` mean that no directly comparable public result was verified. The OpenAI and Anthropic benchmark columns use publisher-reported results with the effort, harness, and safeguard caveats in the footnotes. **All AA Intelligence Index values use the v5.0 scale** (re-based from v4.3.2 on October 31, 2026), so they are not comparable with earlier snapshots.

`MiniMax M3.1 Flash` is a different model, so it has its own row. `Kimi K3.1 Pro` has its own row at 46. MiMo V2.6 Flash now has an OpenRouter composite score (26.7), so it appears in the main table; its Xiaomi-reported launch results are still collected in the MiMo V2.6 Flash launch results section below. Pro UltraSpeed is the latency-focused service tier of Pro, so it shares Pro's score while remaining a separate priced API entry.

Under v5.0, the exact `qwen/qwen3.8-max-0902` metadata row reports **33.6**, which is the score shown for Qwen 3.8 Max.

The Terminal-Bench 4.0 and AutomationBench columns merge the OpenAI and Anthropic/Zapier values into single columns; where the two sources disagree, the cell keeps the model publisher's own result and the footnotes record the other value. Unless noted, Anthropic's results use adaptive thinking at max effort. ## Column definitions: what each benchmark measures

| Benchmark                      | What it measures                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AA Intelligence Index**      | Current v5.0 composite score (0–100) aggregating nine evaluations: AA-Briefcase v1.1, AutomationBench-AA, Terminal-Bench 4.0, FrontierCode 2.0, AA-Omniscience v1.1, GDP.pdf, HLE-Diamond, CritPt v2 (Hard Subset), and Terminal-Bench-Science 0.1. Measures agentic work, coding, reasoning, knowledge, and long-context performance. Source: [Artificial Analysis](https://artificialanalysis.ai/evaluations/artificial-analysis-intelligence-index). |
| **Terminal-Bench 4.0**         | Agentic terminal benchmark covering software engineering, system configuration, and data-analysis tasks. The merged column combines OpenAI's GPT-6 Astra comparison values with Anthropic's own reproductions for the Claude models; effort settings are documented in the footnotes. Sources: [OpenAI](https://openai.com/index/gpt-6-astra/) and [Anthropic](https://www.anthropic.com/claude-opus-5-5).                                              |
| **FrontierCode v1.1 Main**     | Agentic coding benchmark evaluating correctness, mergeability, test quality, scope discipline, code style, and repository standards. Source: [Cognition](https://cognition.com/frontiercode).                                                                                                                                                                                                                                                           |
| **CursorBench 4.0**            | Agentic coding benchmark reported in Anthropic's Opus 5.5 comparison. Source: [Anthropic](https://www.anthropic.com/claude-opus-5-5).                                                                                                                                                                                                                                                                                                                   |
| **GDPval-AA v2.1**             | Knowledge-work evaluation across 44 occupations, reported as Elo. Source: [Artificial Analysis](https://artificialanalysis.ai/evaluations/gdpval-aa).                                                                                                                                                                                                                                                                                                   |
| **ARC-AGI-3**                  | Abstract reasoning benchmark measuring adaptation to novel interactive environments. Values in the main table are from OpenAI's reported comparison. Source: [OpenAI](https://openai.com/index/gpt-6-astra/).                                                                                                                                                                                                                                           |
| **FrontierMath Tier 4 (v2)**   | Advanced mathematical problem-solving evaluation at the highest reported tier. Values in the main table are from OpenAI's reported comparison. Source: [OpenAI](https://openai.com/index/gpt-6-astra/).                                                                                                                                                                                                                                                 |
| **AutomationBench**            | Professional-work automation benchmark covering multi-step knowledge-work tasks. The merged column combines OpenAI's comparison values with Zapier's public leaderboard results; the Opus 5.5 early-access run counted safeguard interventions as failures. Sources: [OpenAI](https://openai.com/index/gpt-6-astra/) and [Anthropic](https://www.anthropic.com/claude-opus-5-5).                                                                        |
| **Humanity's Last Exam**       | Multidisciplinary reasoning benchmark; main-table values use tools where reported. Source: [Humanity's Last Exam](https://lastexam.ai/).                                                                                                                                                                                                                                                                                                                |
| **Terminal-Bench Science 0.1** | Agentic scientific-research benchmark using code and terminal workflows. Source: [Anthropic](https://www.anthropic.com/claude-opus-5-5) and [OpenAI](https://openai.com/index/gpt-6-astra/).                                                                                                                                                                                                                                                            |
| **OSWorld 2.0**                | Computer-use benchmark covering long-horizon workflows; reported values are partial scores. Source: [OSWorld](https://osworld-v2.xlang.ai/).                                                                                                                                                                                                                                                                                                            |
| **Chartography**               | Visual chart-recognition benchmark; main-table values use tools where reported. Source: [Anthropic](https://www.anthropic.com/claude-opus-5-5).                                                                                                                                                                                                                                                                                                         |

## Adding scores

To add benchmark scores for other models, submit a PR with the exact benchmark version, effort/configuration, and source. Do not combine vendor-reported scores from different benchmark versions into the main comparison. Prefer linking to the existing model doc under `docs/models/` rather than duplicating setup details here.
