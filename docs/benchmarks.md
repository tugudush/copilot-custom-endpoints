# Benchmark Scores

A comparison of models available through **GitHub Copilot** (native or extension), custom endpoints, and comparison-only API rows.

## How to read this table

- **Ordering:** rows are sorted by the **AA Intelligence Index** score, highest first; models without a current composite would be listed after scored rows.
- **AA Intelligence Index:** the current **v5.0/v5.0.1** composite from OpenRouter's model metadata (Artificial Analysis' model page where OpenRouter has no row). Scores are not comparable with pre-v5.0 snapshots. For thinking-level models the footnotes state the measured level and any lower-effort scores.
- **Benchmark columns:** publisher-reported results (OpenAI, Anthropic, Google, Meta) plus independent leaderboard runs (Artificial Analysis, Zapier, Cursor). The columns are **not one uniform leaderboard**: where sources disagree, the cell keeps the model publisher's own result and the footnote records the alternative. Unless noted, Anthropic results use adaptive thinking at max effort.
- **`—` cells:** no directly comparable public result was verified. Results from a different benchmark version (e.g. Terminal-Bench 4.1 vs this table's 4.0) or a different metric are not placed in cells; footnotes list them where useful.
- **Footnotes** carry each row's provenance: source, effort/thinking level, harness, tool condition, and known measurement caveats.

## Adding scores

To add benchmark scores for other models, submit a PR with the exact benchmark version, effort/configuration, and source. Do not combine vendor-reported scores from different benchmark versions into the main comparison. Prefer linking to the existing model doc under `docs/models/` rather than duplicating setup details here.
