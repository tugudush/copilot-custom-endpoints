# Benchmark Scores

A comparison of models available through **GitHub Copilot** (native or extension), custom endpoints, and comparison-only API rows. Rows are ordered by the **current OpenRouter AA Intelligence Index** score (highest first); models without a current composite are listed after scored rows. Cells with `—` mean that no directly comparable public result was verified. The OpenAI and Anthropic benchmark columns use publisher-reported results with the effort, harness, and safeguard caveats documented below. Values were checked against live sources on September 30, 2026; the Qwen rows were re-checked on October 7, 2026, the Claude Haiku 5.5 row was added on October 8, 2026, the Gemini 4 Argon row was added on October 14, 2026, the Muse Spark 1.3 row was added on October 16, 2026, and the DeepSeek row was updated to the V4.1-Flash-1017 build on October 20, 2026, the MiniMax M3.1 Flash row was added on October 24, 2026, and the Kimi K3.1 Pro row was added the same day. **All AA Intelligence Index values in this table were re-based from v4.3.2 to v5.0 on October 31, 2026**, and the GPT-6.1 Terra row was added the same day; the per-model notes below quote AA speed, verbosity, and cost-per-task figures from the earlier v4.3.2 runs. Nine rows carry no v5.0 composite — GPT-5.6 Luna, Qwen 3.8 Max (0803), Grok 4.6, GPT-6 Sol, Claude Sonnet 5, GPT-5.6 Terra, GPT-5.6 Sol, Claude Opus 5, and Claude Fable 5 — and are listed after the scored rows; their order within that group is carried over from the previous record and is not a ranking.

`MiniMax M3.1 Flash` is a different model, so it has its own row; M3 itself remains in the table because it is still served. `Kimi K3.1 Pro` is a post-trained successor to K3, so it has its own row at 46 while K3 (17.4) stays listed because Moonshot still serves it. MiMo V2.6 Flash now has an OpenRouter composite score (26.7), so it appears in the main table; its Xiaomi-reported launch results are still collected in the MiMo V2.6 Flash launch results section below. Pro UltraSpeed is the latency-focused service tier of Pro, so it shares Pro's score while remaining a separate priced API entry.

The **53.4 (#3)** figure that OpenRouter’s rankings card attaches to unversioned Qwen3.8 Max is a **v4.3.2** result and is no longer comparable with this table. Under v5.0, the exact `qwen/qwen3.8-max-0902` metadata row reports **33.6**, and AA’s current leaderboard publishes no v5.0 composite for the historical 0803 comparison record. The table therefore scores 0902 only and leaves the 0803 row unscored. Do not treat those values as interchangeable, and do not mix the pre-re-baseline 53.4 with the v5.0 column.
