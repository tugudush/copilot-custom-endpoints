# Benchmark Scores

A comparison of models available through **GitHub Copilot** (native or extension), custom endpoints, and comparison-only API rows. Rows are ordered by the **current OpenRouter AA Intelligence Index** score (highest first); models without a current composite are listed after scored rows. Cells with `—` mean that no directly comparable public result was verified. The OpenAI and Anthropic benchmark columns use publisher-reported results with the effort, harness, and safeguard caveats in the footnotes. **All AA Intelligence Index values use the v5.0 scale** (re-based from v4.3.2 on October 31, 2026), so they are not comparable with earlier snapshots. Artificial Analysis has since relabelled the index **v5.0.1** without changing the ordering below; `Gemini 4 Carbon` enters at **60**, the current v5.0.1 value (Google's October 28 launch post listed **59** under v5.0).

`MiniMax M3.1 Flash` is a different model, so it has its own row. `Kimi K3.1 Pro` has its own row at 46. MiMo V2.6 Flash now has an OpenRouter composite score (26.7), so it appears in the main table; its Xiaomi-reported launch results are still collected in the MiMo V2.6 Flash launch results section below. Pro UltraSpeed is the latency-focused service tier of Pro, so it shares Pro's score while remaining a separate priced API entry.

`Gemini 4 Carbon` is the second-highest scored model here and the highest-scoring Copilot-native model below Claude Fable 5.2. It is priced identically to Argon, but Google positions it as the more deliberate, higher-token-spend option and keeps Argon as the default for most software-engineering work.

`Gemini 4 Hydrogen` (released November 12, 2026) is API-only — Google AI Studio and the Gemini API, with a free tier — so it is not Copilot-native. It scores **54** on the current v5.0.1 index at its `xhigh` thinking level and **51** at the default `high` level, which places it between Claude Sonnet 5.5 and GPT-6.1 Terra in this ordering.

Under v5.0, the exact `qwen/qwen3.8-max-0902` metadata row reports **33.6**, which is the score shown for Qwen 3.8 Max.

## Adding scores

To add benchmark scores for other models, submit a PR with the exact benchmark version, effort/configuration, and source. Do not combine vendor-reported scores from different benchmark versions into the main comparison. Prefer linking to the existing model doc under `docs/models/` rather than duplicating setup details here.
